# Marvel_3D_Display 🕷️

An interactive 3D Marvel universe built with **Three.js**, where superheroes are represented inside a dynamic 3D Earth environment.

## 🚀 Project Vision

The goal is to build an immersive website where users can:

* 🌍 Explore a 3D Earth
* 🦸 Discover Marvel superheroes
* 📍 See where each hero is located
* 🕷️ Interact with individual characters
* 🔎 Explore character information
* ⚡ Expand the world with more heroes and locations

## 🛠️ Tech Stack

* Three.js
* JavaScript
* HTML / CSS
* Vite
